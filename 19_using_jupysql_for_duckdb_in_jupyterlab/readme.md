# Использование JupySQL в JupyterLab

Документация:

- [Python API](https://duckdb.org/docs/current/clients/python/overview)
- [Python DB API](https://duckdb.org/docs/current/clients/python/dbapi)
- [Jupyter Notebooks](https://duckdb.org/docs/current/guides/python/jupyter)
- [JupySQL](https://github.com/ploomber/jupysql)
- [jupyter](https://jupyter.org/)
    - [jupyterlab](https://pypi.org/project/jupyterlab/)

Для запуска JupyterLab необходимо перейти в корень проекта и выполнить команду:

```bash
uv run jupyter lab
```

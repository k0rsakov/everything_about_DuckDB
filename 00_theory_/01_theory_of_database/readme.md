#### Кратко
- ACID – про надёжность и корректность транзакций (DuckDB поддерживает).
- BASE – про гибкость и eventual consistency, важно для распределённых NoSQL.
- CAP – ограничение для распределённых систем.
- OLTP – про транзакции, OLAP – про аналитику.  
DuckDB = OLAP + ACID, single-node, без сложностей кластера.

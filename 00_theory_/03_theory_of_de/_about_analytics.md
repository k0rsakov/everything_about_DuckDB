# Кратко про аналитику

В мире данных существует несколько ключевых направлений аналитики, каждое из которых решает свои задачи и требует разных
подходов и инструментов. Важно понимать различия между ними, чтобы правильно выбирать инструменты и строить архитектуру
решения.

## Операционная аналитика (Operational Analytics, Real-time/Online Analytics)

- **Что это:**
    - Аналитика, поддерживающая принятие решений "_здесь и сейчас_". Используется для мониторинга процессов, выявления
      отклонений, автоматических реакций на события — всё это происходит в реальном времени или с минимальной
      задержкой (seconds/minutes).
- **Примеры:**
    - Система антифрода в банке — блокировка подозрительных транзакций на лету.
    - Рекомендации товаров на сайте в момент просмотра.
    - Отслеживание показателей серверов и автоматическое масштабирование.
- **Требования:**
    - Минимальная задержка.
    - Высокая производительность.
    - Часто — потоковые системы (Kafka, Flink, ClickHouse).
- **Чем отличается:**
    - Обычно работает с текущими данными, часто требует OLTP/streaming решений. DuckDB — не основной инструмент для
      оперативной аналитики, но может использоваться для разбора стримов “_батчами_”.

## Бизнес-аналитика (Business Intelligence, BI)

- **Что это:**
    - Анализ исторических данных для поддержки принятия бизнес-решений, построения отчётов, дашбордов, мониторинга KPI.
- **Примеры:**
    - Ежедневные/еженедельные/ежемесячные отчёты по продажам, клиентам, доходам.
    - Анализ эффективности маркетинговых кампаний.
    - Выявление трендов, сезонности, аномалий.
- **Требования:**
    - Работа с большими объёмами исторических данных.
    - Часто — агрегации, группировки, сложные фильтры.
    - Интеграция с BI-инструментами (PowerBI, Tableau, Superset, Metabase).
- **Чем отличается:**
    - Работа в основном с OLAP-системами и DWH (Data Warehouse). DuckDB подходит идеально: быстрая аналитика, интеграция
      с BI, поддержка SQL.

## Data Science / Моделирование / ML-аналитика

- **Что это:**
    - Глубокий анализ данных, построение моделей, прогнозирование, A/B-тесты, машинное обучение.
- **Примеры:**
    - Построение моделей для прогнозирования спроса/оттока клиентов.
    - Кластеризация пользователей.
    - Обработка и анализ больших датасетов для подготовки данных к ML.
- **Требования:**
    - Гибкая работа с разными форматами данных (`.csv`, `.parquet`, `.json`, `df` (Pandas, Polars))
    - Возможность преобразований, фильтраций, feature engineering.
    - Интеграция с Python/ML-стеком (Pandas, scikit-learn, PyTorch).
- **Чем отличается:**
    - Часто требует выгрузки данных из БД в датафреймы, соединения с Python-экосистемой. DuckDB — уникален тем, что
      позволяет "_уткой_" читать, обрабатывать, выгружать данные прямо в Pandas/Polars, не теряя производительности.

## Прочее: Ad-hoc, Exploratory, Product Analytics

- **Ad-hoc аналитика:**
    - Быстрые разовые запросы, проверки гипотез, исследование неожиданных аномалий.
- **Exploratory Data Analysis (EDA):**
    - "_Разведочный_" анализ, визуализация, выявление закономерностей.
- **Product Analytics:**
    - Анализ поведения пользователей, воронки, retention, когорты.

Не подходит для полноценного real-time стриминга, но прекрасно справляется с аналитикой и подготовкой данных для ML/BI.

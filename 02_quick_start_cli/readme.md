# Быстрый старт через CLI

Для запуска DuckDB локально необходимо установить через пакетный менеджер. Более подробно в
документации — [DuckDB Installation](https://duckdb.org/install/?platform=macos&environment=cli)

Для быстрого запуска DuckDB выполните команду:

```bash
duckdb
```

> Будет работать в формате `in-memory`

Запуск DuckDB с указанием файла базы данных:

```bash
duckdb duckdb.duckdb
```

> Создаст физически файл базы данных.
> 
> Соответственно, все наши манипуляции с базой данных будут сохраняться в этом файле, и мы сможем продолжить работу с базой данных в будущем, используя этот же файл.
